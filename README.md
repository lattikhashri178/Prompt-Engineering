#  Prompt Comparison using LLM

##  Project Description

Prompt Comparison is a simple Large Language Model (LLM) application that demonstrates how different prompting techniques can produce different responses from an AI model.

The application uses **Groq API** with an LLM and provides three different prompt styles:

- Basic Prompt
- Detailed Prompt
- Structured Prompt

The generated prompts are sent to the LLM, and the responses are displayed in a user-friendly Streamlit interface.

---

##  Objectives

The main objectives of this project are:

1. To understand the concept of Large Language Models.
2. To understand different prompting techniques.
3. To compare responses generated using different prompts.
4. To integrate an LLM API into a Python application.
5. To build an interactive user interface using Streamlit.

---

##  Technologies Used

- **Python**
- **Streamlit**
- **Groq API**
- **Large Language Model (LLM)**
- **python-dotenv**
